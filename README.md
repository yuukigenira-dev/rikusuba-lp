# りくすば（理来 × 昴）総合サイト

創作BL「りくすば日記」（理来 × 昴）の総合ポータルと、作品ごとのLP・ブラウザゲームの
ホスティング用リポジトリ。

GitHub Pages で配信：https://yuukigenira-dev.github.io/rikusuba-lp/

## 構成

```
/index.html                     総合ポータル（作品一覧）
/assets/                        ポータル用アセット
/beach-house/index.html         「渚のふたり計画」ゲームLP
/beach-house/assets/            ゲームLP用アセット（画像・動画）
/beach-house/game/index.html    ゲーム本体（単一HTML・約4.8MB）
```

作品を追加するときは `/<作品スラッグ>/` を切り、その中に `index.html`（LP）・`assets/`・
`game/` を置く。ポータルの WORKS セクションにカードを1枚足せば導線がつながる。

## 導線とパスの約束

ページ間はすべて相対パスで結ぶ（独自ドメインへ移しても壊れないようにするため）。

| 参照元 | 参照先 | 書き方 |
|---|---|---|
| ポータル | ゲームLP | `beach-house/` |
| ゲームLP | ポータル（のれん左端） | `../` |
| ゲームLP | ゲーム本体 | `game/`（CTA 3箇所＋試遊iframe 1箇所） |

例外は2種類だけ。

- **OGP画像**：SNS展開に絶対URLが必要なため、各ページで絶対URLを書いている
  （ポータル → `/assets/ogp.jpg`、ゲームLP → `/beach-house/assets/ogp.jpg`）
- **ゲーム本体のエンドカード「公式サイトへ」**：iframe内から最上位フレームごと
  遷移させる必要があるため、`target="_top"` とルートの絶対URLを使っている

いずれも独自ドメインへ移行する際は書き換えが必要。

## ゲーム本体（/beach-house/game/）について

単一HTMLファイルで完結したブラウザゲーム。画像45点（JPEG 33／PNG 12）と
BGM 3点を base64 で内包しているため、外部アセットへの依存はゼロ。

- ファイルサイズ：約 4.8MB
- 外部ネットワーク参照：エンドカードの公式サイトリンクのみ
- 想定表示幅：最大 520px（スマートフォン縦持ち基準、`100dvh` 使用）

### 既知の技術的トレードオフ

base64 内包により、以下の性質がある。将来的にアセットを外部ファイルへ分離する場合の判断材料。

- ブラウザキャッシュが効く単位がファイル全体になるため、アクセスごとに約 4.8MB を再取得する
- base64 エンコードによりバイナリが約 33% 膨張している
- ゲーム本体を更新するたび、Git 履歴に約 4.8MB のブロブが追加される

## 履歴上の注意

2026-07-27 の階層移行以前は、`/beach-house/` がゲーム本体そのものだった。
移行後は同じURLがゲームLPを返す。旧URLからでもLP経由でゲームに到達できるため、
リダイレクトは設けていない。

## デプロイ

`main` ブランチへの push で GitHub Pages が自動的に更新される。
ビルド工程はなく、リポジトリ内のファイルがそのまま配信される。
