# りくすば日記 LP

創作BL「りくすば日記」（理来 × 昴）の公式LPサイトと、関連ブラウザゲームのホスティング用リポジトリ。

GitHub Pages で配信：https://yuukigenira-dev.github.io/rikusuba-lp/

## 構成

```
/                    LPサイト（制作中 — 現在はプレースホルダ）
/beach-house/        ブラウザゲーム「渚のふたり計画 — 理来と昴の海の家」
```

## /beach-house/ について

単一HTMLファイルで完結したブラウザゲーム。画像45点（JPEG 33／PNG 12）と
BGM 3点を base64 で内包しているため、外部アセットへの依存はゼロ。
ファイルを開くだけで動作する。

- ファイルサイズ：約 4.8MB（`beach-house/index.html`）
- 外部ネットワーク参照：なし
- 想定表示幅：最大 520px（スマートフォン縦持ち基準、`100dvh` 使用）

### 既知の技術的トレードオフ

base64 内包により、以下の性質がある。将来的にアセットを外部ファイルへ分離する場合の判断材料。

- ブラウザキャッシュが効く単位がファイル全体になるため、アクセスごとに約 4.8MB を再取得する
- base64 エンコードによりバイナリが約 33% 膨張している
- ゲーム本体を更新するたび、Git 履歴に約 4.8MB のブロブが追加される

## デプロイ

`main` ブランチへの push で GitHub Pages が自動的に更新される。
ビルド工程はなく、リポジトリ内のファイルがそのまま配信される。
